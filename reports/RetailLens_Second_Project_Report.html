Second Project Progress Report

RetailLens

Retail Sales Forecasting & Analytics

Date: 29 September 2026 Stage: Evaluation and dashboard integration Dataset: Store Item Demand Forecasting Challenge

1. Project Overview

RetailLens analyzes historical retail sales, compares forecasting models, and presents demand insights through a Streamlit dashboard to support inventory planning.

2. Progress So Far

  • Created a data-cleaning pipeline and processed sales dataset.
  • Implemented calendar, lag, and rolling features for sales forecasting.
  • Built Prophet, SARIMA, and XGBoost model workflows and saved evaluation outputs.
  • Developed a Streamlit dashboard with sales filters, charts, forecast/model views, downloads, and demand-based attention alerts.
  • Added forecasting and machine-learning test suites; a passing test run has not yet been verified for this report.

4. Next Work

  1. Re-run all models on the same holdout dates and metric definitions; correct the inconsistent comparison and best-model selection.
  2. Add prediction intervals for XGBoost and evaluate their coverage and width.
  3. Test 30-, 60-, and 90-day forecasts across more store-item series, then summarize overall performance.
  4. Run the test suites and verify the dashboard workflow, forecast selection, and alert labels.
  5. Connect actual inventory data before presenting demand-based alerts as low-stock warnings.

5. Conclusion

The core forecasting modules and dashboard prototype are in place. The next phase will focus on consistent model evaluation, uncertainty estimates, broader testing, and verified dashboard behavior before selecting a final model.
